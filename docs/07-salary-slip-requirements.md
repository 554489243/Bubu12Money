# 工资单功能需求

## 概述

选择"工资"子分类时，弹出工资单编辑弹窗，自动化工资计算，生成文本格式备注。

## 功能设计

### 触发条件

选择"工资"父类下的子分类（如"基本工资"、"奖金"、"补贴"）时弹出工资单弹窗。

### 工资单项目

| 项目 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 基本工资 | 收入 | ¥5,100 | 固定收入 |
| 电脑补贴 | 收入 | ¥200 | 固定收入 |
| 通讯补贴 | 收入 | ¥100 | 固定收入 |
| 加班费 | 收入 | ¥0 | 按需填写 |
| 请假扣除 | 扣除 | ¥0 | 按需填写 |
| 防暑费 | 收入 | ¥0 | 按需填写 |
| 养老 8% | 扣除 | 自动计算 | 基本工资 × 8% |
| 医疗 2% | 扣除 | 自动计算 | 基本工资 × 2% |
| 失业 0.5% | 扣除 | 自动计算 | 基本工资 × 0.5% |
| 公积金 12% | 扣除 | 自动计算 | 基本工资 × 12% |
| 个税 | 扣除 | 自动计算 | 应纳税所得额 × 税率 |

### 计算逻辑

```
应发合计 = 基本工资 + 电脑补贴 + 通讯补贴 + 加班费 + 防暑费 - 请假扣除
三金合计 = 养老 + 医疗 + 失业
公积金 = 基本工资 × 12%
应纳税所得额 = 应发合计 - 三金 - 公积金 - 5000（起征点）
个税 = 应纳税所得额 × 税率（3%/10%/20%...）
实发金额 = 应发合计 - 三金 - 公积金 - 个税
```

### 用户交互

1. 勾选项目是否启用（默认全部启用）
2. 修改各项金额
3. 点击确认 → 计算实发金额
4. 生成文本格式备注，填入记账备注字段

### 备注格式

```
—— 工资单 ——
基本工资 5100.00
电脑补贴 200.00
通讯补贴 100.00
...
实发金额 4349.70
```

### 默认值持久化

- 用户修改后的默认值保存到 localStorage（`salaryDefaults` 和 `salaryEnabled`）
- 下次打开弹窗自动填充

## 技术实现

- 弹窗组件：van-popup + 自定义表单
- 计算属性：`salaryIncomeTotal`、`salaryThreeGold`、`salaryTaxable`、`salaryNet`
- 存储：localStorage
