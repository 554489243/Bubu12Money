# 基本需求

## 产品定位

一款面向个人的轻量级记账应用，核心特点：

- **零服务器成本**：纯前端静态资源，部署于 GitHub Pages / Vercel
- **离线优先**：数据存于浏览器 IndexedDB，无需网络
- **PWA 体验**：可添加到桌面，离线可用
- **初版聚焦**：仅支出记账，功能做深做透

## 功能清单

### 1. 主页（Home）

- 顶部视图切换：今日 / 本月
- 今日视图：今日支出合计
- 本月视图：本月支出合计
- 最近账单列表（默认 10 条，按时间倒序）
- 底部悬浮「记一笔」按钮（FAB）
- 点击账单条目 → 跳转记账页（编辑模式）

### 2. 记账页（Edit）

- 金额输入：数字键盘，小数点后 2 位
- 金额显示格式：￥10.88
- 分类选择：3×3 网格展示 9 个支出分类，点击选中
- 日期选择：默认今天，可修改
- 备注：可选输入
- 保存按钮：校验金额 > 0、分类已选
- 编辑模式：从明细/主页跳转而来，显示「删除」按钮

### 3. 明细页（List）

- 账单列表，按日期倒序排列
- 按日期分组，显示每日小计
- 筛选：按月份、按分类
- 左滑删除（Vant SwipeCell）
- 点击条目 → 编辑
- 空状态：插画 + 提示文字 + 记一笔入口

### 4. 统计页（Stats）

- 月份选择器
- 近 6 个月月度支出柱状图（ECharts）
- 分类占比饼图（ECharts）
- 各分类金额 + 占比列表

### 5. 我的（Profile）

- 分类展示（只读，展示内置分类）
- 关于：版本号、技术栈说明

## 交互细节

| 场景 | 行为 |
|------|------|
| 保存账单 | 金额 > 0、分类已选，否则 Toast 提示 |
| 删除账单 | 左滑露出删除按钮 → 点击后二次确认弹窗 |
| 金额输入 | 实时格式化为 ￥xx.xx 显示 |
| 分类选择 | 选中态高亮，单选 |
| 日期选择 | 弹窗日期选择器，默认今天 |
| 空列表 | 显示空状态提示 |
