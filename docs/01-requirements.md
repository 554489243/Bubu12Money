# 基本需求

## 产品定位

一款面向个人的轻量级记账应用，核心特点：

- **零服务器成本**：纯前端静态资源，部署于 GitHub Pages
- **离线优先**：数据存于浏览器 IndexedDB，无需网络
- **PWA 体验**：可添加到桌面，离线可用
- **数据归档**：1 年前数据自动归档到历史表，保持实时表轻量

## 功能清单

### 1. 明细页（List）— 首页 `/`

- 顶部账本选择器（下拉切换账本 + 装饰图片）
- 概览卡片：总支出 + 总收入 + 笔数
- 月份选择器（上一月/下一月/全部）
- 分类筛选：一级分类横排 + 二级分类展开
- 账单列表：按日期分组，显示每日小计
- 左滑删除（Vant SwipeCell）
- 历史数据（>1年）：只读显示，不可编辑/删除，显示"📦 历史数据（只读）"提示
- 空状态提示

### 2. 统计页（Stats） `/stats`

- 顶部账本选择器
- 视图切换：本周 / 本月 / 本年
- 趋势图（ECharts 柱状图）：收支对比
- 支出饼图：分类占比
- 收入饼图：分类占比
- 图表联动：随视图切换更新
- 跨年数据：自动合并历史表

### 3. 记账页（Edit） `/edit`

- 类型切换：支出 / 收入（顶部）
- 金额显示区（sticky 顶部）
- 自定义计算器键盘（固定在底部）
  - 4行×5列：数字 + 运算符 + 等号
  - 支持加减乘除运算优先级
  - C 键清空
  - 保存按钮嵌入键盘
- 分类选择：一级分类横排 + 二级分类展开
  - 子类含默认金额 → 自动填入表达式
  - 不选分类 → 默认"其他"
  - 只选父类 → 用父类 ID
- 日期选择（默认今天）
- 备注输入
- 账本选择（chips 网格）
- 工资单功能：选择"工资"分类时弹出工资单编辑弹窗
- 编辑模式：加载已有记录，可删除

### 4. 我的（Profile） `/profile`

- 头像区域
- 账本管理入口
- 分类管理入口
- 数据归档入口（显示可归档条数，确认后归档）
- 云端同步（占位）
- 关于（占位）

### 5. 账本管理（Books） `/books`

- 账本卡片列表
- 创建/编辑/删除账本
- 排序（上移/下移）
- 隐藏/显示账本
- 默认账本保护

### 6. 分类管理（Categories） `/categories`

- 支出/收入切换
- 一级分类组（带颜色左边框）
- 二级分类列表
- 内置分类：不可删除/改名/改图标，可改默认金额
- 自定义分类：完整 CRUD
- 图标选择器（38 个 emoji）
- 默认金额设置（子类）

## 数据归档功能

- **归档时机**：每周检查一次 + 手动触发
- **归档条件**：当前日期 - 1 年之前
- **归档操作**：旧记录 → 历史表，实时表删除
- **历史数据**：只读查看，不可编辑/删除
- **统计查询**：跨年自动合并两表

## 交互细节

| 场景 | 行为 |
|------|------|
| 保存账单 | 金额 > 0 校验，分类默认"其他"，无需强制选择 |
| 删除账单 | 左滑露出删除按钮 → 点击后二次确认弹窗 |
| 金额输入 | 自定义键盘，实时表达式计算，支持四则运算 |
| 分类选择 | 一级横排 + 二级展开，选中子类自动填默认金额 |
| 日期选择 | 弹窗日期选择器，默认今天 |
| 空列表 | 显示空状态提示 |
| 键盘 | 固定在底部，内容区可滚动 |
| 归档 | Profile 页面点击，确认弹窗，显示归档条数 |
| 饼图交互 | hover/点击扇形显示 tooltip（分类 + 金额 + 占比） |
| 账本排序 | 长按 ⠿ 手柄拖动调整顺序 |

## 数据导出/导入

- **导出**：生成 JSON 备份文件（含 records/categories/books 全量数据）
- **导入**：智能合并，分类/账本跳过已存在，记录按 ID 合并
- **自动备份**：每月 1 号/15 号打开应用时静默导出（同一天只备一次）
- **PWA 兼容**：导出用 Web Share API，导入用 label 关联文件选择

## 技术要点

| 要点 | 实现 |
|------|------|
| 金额存储 | 分（cents），显示时 ÷100 |
| 金额显示 | ￥10.88 格式 |
| 分类颜色 | 预定义颜色系统（bg/text/light） |
| 图表渲染 | ECharts Canvas 模式 |
| 路由模式 | Hash 路由（PWA 兼容） |
| 键盘安全 | 简单数学解析器，不用 Function() |
| 滚动条 | 全局隐藏（scrollbar-width: none） |
| 内置标记 | builtin 字段区分内置/自定义 |
| 归档历史 | 双表（records + records_history） |
