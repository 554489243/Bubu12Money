# 多账本功能需求

## 概述

在现有记账功能基础上，新增「账本」概念。用户可以创建多个独立账本（如"日常"、"国庆旅游"、"生意"），每个账本拥有独立的收支记录和统计数据。

## 核心概念

- **账本（Book）**：独立的记账容器，拥有自己的记录和统计
- **默认账本**：首次使用自动创建"日常"账本
- **全部视图**：默认展示所有账本的汇总数据
- **单账本视图**：筛选查看某个账本的独立数据

## 功能清单

### 1. 账本管理

| 功能 | 说明 |
|------|------|
| 创建账本 | 名称 + 图标/颜色，如"国庆旅游"🏖️ |
| 编辑账本 | 修改名称、图标、颜色 |
| 删除账本 | 删除账本及其全部记录（需二次确认） |
| 默认账本 | 可设置某个账本为默认记账账本 |

### 2. 记账关联

| 功能 | 说明 |
|------|------|
| 新建记账 | 可选择记在哪个账本（默认当前账本） |
| 编辑记账 | 可切换账本归属 |
| 账本字段 | 每条记录关联 `bookId` |

### 3. 数据筛选

| 页面 | 行为 |
|------|------|
| 首页 | 顶部下拉切换账本，默认"全部" |
| 明细 | 顶部下拉切换账本，默认"全部" |
| 统计 | 顶部下拉切换账本，默认"全部" |
| 账本管理 | 独立页面，列表展示所有账本 |

### 4. 数据展示

- **全部视图**：汇总所有账本的收支数据
- **单账本视图**：仅展示选中账本的数据
- **首页卡片**：显示当前选中账本的收支概览
- **明细分组**：按日期分组，显示收支明细

## 数据模型

### Book 表

```typescript
interface Book {
  id?: number
  name: string          // 账本名称
  icon: string          // 图标（emoji）
  color: string         // 主题色
  sort: number          // 排序
  isDefault: boolean    // 是否为默认
  createdAt: number
}
```

### Record 表扩展

```typescript
interface Record {
  // ... 现有字段
  bookId: number        // 关联账本ID
}
```

## 页面交互

### 账本切换器（顶部下拉）

```
[全部 ▼]  → 点击展开下拉列表
  ├── 全部
  ├── 📱 日常（默认）
  ├── 🏖️ 国庆旅游
  ├── 💼 生意
  └── ＋ 新建账本
```

### 新建/编辑账本

- 名称输入（必填，最多10字）
- 图标选择（emoji 网格）
- 颜色选择（预设色板）
- 保存/取消

### 账本管理页

- 账本卡片列表
- 每张卡片显示：图标、名称、记录数、总支出/收入
- 左滑编辑/删除
- 右下角"新建账本"按钮

## 默认行为

1. 首次使用自动创建"日常"账本并设为默认
2. 新建记账默认使用当前选中的账本
3. 删除账本时，若该账本有记录，需二次确认
4. 不能删除最后一个账本

## 技术要点

- 新增 `books` 表（Dexie.js）
- 现有 `records` 表增加 `bookId` 索引
- 新增 `bookStore.ts`（Pinia）
- 现有页面增加账本筛选逻辑
- 数据迁移：为已有记录添加默认 `bookId`
